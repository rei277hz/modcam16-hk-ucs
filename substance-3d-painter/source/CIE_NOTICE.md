# CIE observer attribution

`CIE_xyz_1931_2deg.csv` is the CIE 1931 colour-matching functions for the
2-degree standard observer, sampled from 360 nm through 830 nm at 1 nm. It is
the 2019 CIE dataset identified by DOI `10.25039/CIE.DS.xvudnb9b` and licensed
CC BY-SA 4.0. The accompanying metadata file is retained beside the data.

The generator verifies the published MD5 checksum
`17cca777db64b17170f06f67ce9d3ab7` before using the data.
